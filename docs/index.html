NeuroKidsDoc Patient Database

Fast, native pediatric neurology diagnosis & patient record manager with Google Workspace authentication and role-based clinical access control.

⬇ Download for Windows (.msi) View on GitHub

🔐 Multi-Domain Google Sign-In

Authenticated via Google OAuth 2.0 PKCE exclusively for authorized clinic staff with @neuropedia.ae and @cdcdubai.ae accounts.

🛡️ Strict Role-Based Access

Full create, update, and delete privileges are restricted to the administrator (stephen.dias@neuropedia.ae), while clinic colleagues have safe Read-Only search access.

⚡ Instant Multi-Field Search

Filter patient records in real time across Name, MRN, Diagnosis, and Clinic Location with sortable columns and dark/light clinical themes.
